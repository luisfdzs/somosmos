# Somos Mos

Web built with Next.js, deployed on Vercel.

| Branch | Environment | URL |
|---|---|---|
| `prod` | Production | https://somosmos.vercel.app |
| `test` | Test | https://somosmostest.vercel.app |
| `dev` | Development (previews) | — |

Workflow: `dev` → `test` → `prod`.

## Local development

```bash
npm install
npm run dev
```
